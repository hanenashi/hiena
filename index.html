Co je v ukázce změněno

Texty, obrázky a původní stolová struktura stránky zůstávají zachované. Na běžném počítači se původní vzhled nemění; úprava se aktivuje jen na úzkých displejích. Odkazy uvnitř ukázek vedou zpět na skutečný web hyena.cz.

viewport
Řekne telefonu, aby stránku vykreslil ve skutečné šířce displeje místo zmenšeného desktopu.
Mobilní CSS
Na displejích do 780 px zruší pevné šířky a sloupce, nastaví čitelné písmo a stejně široké okraje.
Krátký JavaScript
Přidá kompaktní hlavičku a přesune původní archiv, odkazy, hledání a tiráž do vysouvacího menu.

Jak úpravu vložit na server Hyeny

Nejsou potřeba změny redakčního systému ani přepis článků. Stačí na server nahrát dva nové soubory a do společné HTML šablony přidat tři řádky. Tím se úprava automaticky použije na každé vydání vytvořené ze stejné šablony.

  1. Nahrát soubor s CSS

    Stáhnout hyena-mobile.css a na serveru jej uložit sem:

    /css/hyena-mobile.css

    CSS obsahuje pouze pravidla vzhledu. Většina změn je uvnitř @media (max-width: 780px), takže původní desktopová Hyena zůstane beze změny.

  2. Nahrát soubor s JavaScriptem

    Stáhnout hiena-mobile.js a na serveru jej uložit sem:

    /js/hiena-mobile.js

    Skript nemění text článku ani odkazy. Najde původní pravý sloupec široký 215 px a doplní pouze tlačítka pro jeho otevření a zavření na telefonu.

  3. Přidat tři řádky do společné HTML šablony

    Následující kód vložit do části <head>, ideálně za stávající řádek content-type a před <title>:

    Tři nové řádky 
    <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
<link rel="stylesheet" href="/css/hyena-mobile.css">
<script defer src="/js/hiena-mobile.js"></script>

    Atribut defer zajistí, že se skript spustí až po načtení původního HTML. Cesty začínající lomítkem fungují stejně na titulní stránce i v adresářích jednotlivých ročníků.

Výsledek v původní hlavičce stránky

Začátek stávajícího HTML by potom vypadal přibližně takto. Řádek s kódováním Windows-1250 může zůstat tak, jak je dnes:

Ukázka celé části <head> 
<html>
<head>
  <meta http-equiv="content-type" content="text/html;charset=windows-1250">
  <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
  <link rel="stylesheet" href="/css/hyena-mobile.css">
  <script defer src="/js/hiena-mobile.js"></script>
  <title>The Hyena</title>
</head>

Pokud má server jiné názvy adresářů, stačí upravit dvě cesty v HTML. Samotné soubory nevyžadují instalaci, databázi ani další knihovny.
